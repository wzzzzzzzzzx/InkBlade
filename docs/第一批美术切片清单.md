# 墨刃 第一批美术切片清单

目标：先完成“凌霜 + 长剑 + 竹林月夜”的最小美术切片，用少量透明 PNG 替换当前程序化占位图，验证角色、武器、特效、背景进入游戏后的真实效果。

## 切片范围

第一批只处理：

- 角色：凌霜
- 武器：长剑
- 场景：竹林月夜
- 用途：单局战斗画面，不覆盖菜单、选人、结算界面

暂不处理：

- 墨痕、素心运行素材
- 大刀、双刃运行素材
- 完整逐帧动画
- Spine/DragonBones 骨骼动画
- 商店、剧情、立绘对话

保存目录：


制作要求：

- 透明背景。
- 默认面向右。
- 人物脚底尽量对齐同一基准线。
- 人物整体高度保持一致，避免不同动作忽大忽小。
- 披风、长发、衣摆可以超出身体框，但不能被裁切。
- 推荐单帧画布：768x768。

- 前景叶片可以半透明，但不要挡住角色主体。
- 远景月亮不要放在 UI 血条附近，避免干扰 HUD。

## 第一版接入优先级

建议按这个顺序进入游戏：

1. 背景整图或分层图。
2. 凌霜 idle_01 替换角色占位绘制。
3. 凌霜 run/jump/dodge/parry/hit 静态帧接入。
4. 长剑平 A 三连轨迹接入。
5. 长剑蓄力与释放接入。
6. 凌霜小技能和大招特效接入。

先不追求完整动画，先验证“素材加载、缩放、朝向、层级、碰撞框和特效位置”都正确。

## 验收标准

第一批美术切片通过的标准：

- 游戏能从 `assets/art/...` 加载 PNG。
- 凌霜在战斗场景中尺寸合适，脚底不漂浮。
- 左右朝向正常，水平翻转后没有明显错误。
- 长剑平 A、蓄力、释放的视觉差异明显。
- 凌霜技能特效不会遮住 HUD。
- 竹林背景能读出地面、角色和敌人，不影响战斗判断。
