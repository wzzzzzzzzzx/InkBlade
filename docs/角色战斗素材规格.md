# 墨刃角色战斗素材规格 v1

本文档定义角色 body sprite 的正式接入标准。目标是让墨痕、素心后续素材质量逐步接近凌霜，并让每次替换素材都能被视觉训练场稳定验证。

## 质量基准

- 凌霜当前战斗图作为第一版质量基准。
- 正式 body sprite 必须是单角色图，不能来自带边框的动作表截图。
- 角色必须完整，不裁切头发、武器、衣摆、披风、飘带等关键轮廓。
- 透明边缘要干净，不能残留白底、表格线、角标、阴影框、色块或脏边。
- 远景下必须能通过剪影区分角色。

## 文件位置

角色 body sprite 固定放在：

```text
assets/art/characters/<character>/sprites/body/
```

角色 ID：

```text
lingshuang
mohen
suxin
```

正式精修母版建议另存为：

```text
idle_refined_01.png
hit_refined_01.png
skill_refined_01.png
ultimate_refined_01.png
```

当前游戏加载文件仍使用：

```text
idle_01.png
hit_01.png
skill_01.png
ultimate_01.png
```

当精修图通过验收后，再覆盖或复制为游戏加载名。

## 画布与锚点

- 推荐画布：透明 PNG，最长边 900-1200 px。
- 角色站立母版必须保留脚底，脚底作为落地点锚点。
- 游戏内缩放后，普通站姿视觉高度应接近凌霜。
- 空白边距建议：上 6%-10%，左右 8%-14%，下 4%-8%。
- `idle` 图必须是稳定站姿，不带大面积技能特效。
- `hit` 图可以有受击姿势和少量受击碎片，但不能遮挡角色主体。
- `skill` 图以角色施法/出招姿态为主，特效范围中等。
- `ultimate` 图中的角色和大招特效需要分层规划；第一版可合图，后续应拆分。

## 大招拆分目标

后续正式版本应拆成两类资源：

```text
assets/art/characters/<character>/sprites/body/ultimate_01.png
assets/art/characters/<character>/sprites/vfx/ultimate_vfx_01.png
```

body 图只保留角色姿态，vfx 图保留墨旋涡、莲花气流、冰棱等大范围效果。这样可以在代码中独立调节缩放、透明度、层级和持续时间。

## 角色风格要求

### 墨痕

- 男性，斗笠，高马尾。
- 主色：黑、白、深蓝、暗紫。
- 轮廓：斗笠宽檐、长袍披摆、高马尾、墨痕衣摆。
- 特效：墨迹、符纸、黑紫旋涡、墨点飞溅。
- 气质：冷静、压迫、控制型。

### 素心

- 女性，中国风旗袍，丸子头，灵性轻盈。
- 主色：青绿、白、粉、金。
- 轮廓：丸子头、飘带、半透明袖摆、旗袍开衩。
- 特效：莲花、青绿气流、花瓣、柔光。
- 气质：灵动、治疗、轻盈。

## 生成提示词规范

生成正式 body sprite 时，必须避免直接模仿任何现有 IP 或商业游戏角色。使用“原创国风武侠 2D 横版格斗角色 sprite”作为风格描述。

通用提示词骨架：

```text
Create an original 2D side-view wuxia fighting game character sprite for a desktop game.
The character must be a full-body single character on a perfectly flat solid #00ff00 chroma-key background for background removal.
Use clean anime-inspired game art, crisp silhouette, detailed costume, readable at small combat scale.
Three-quarter side-facing pose, feet visible, no cropping, generous padding, no frame, no UI, no text, no watermark.
No cast shadow, no floor plane, no gradient background, no border, no panel corners.
Do not use #00ff00 anywhere in the character.
```

## 验收流程

1. 生成或导出素材到角色 `sprites/body/` 目录。
2. 检查文件命名和透明背景。
3. 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\check_character_visual_profiles.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\check_character_battle_art_spec.ps1
```

4. 构建并打包：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

5. 执行视觉训练场：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\visual_combat_test.ps1
```

6. 对比 `build/visual-lab/visual_lab_char*_*.png`，确认三角色比例、锚点、边缘和动作辨识度。
