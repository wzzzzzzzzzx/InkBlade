# 墨刃 美术素材接入规范

本文档用于把当前 AI 概念母版整理成后续可进入游戏运行的素材结构。当前阶段先保存概念图和制作规范，后续再逐步拆分透明 PNG、序列帧、特效帧与图集。

## 目录分层

`concept` 目录只放美术参考，不直接给游戏运行时读取：

```text
assets/art/characters/<角色id>/concept/
assets/art/weapons/<武器id>/concept/
```

`sprites` 目录放未来真正进入游戏的透明 PNG、序列帧和图集：

```text
assets/art/characters/<角色id>/sprites/
assets/art/weapons/<武器id>/sprites/
assets/art/vfx/<特效id>/
```

推荐角色 id：

```text
lingshuang  凌霜
mohen       墨痕
suxin       素心
```

推荐武器 id：

```text
longsword   长剑
broadsword  大刀
dualblades  双刃
```

## 角色素材

角色素材只负责人物外观、通用动作、角色专属小技能、大招和被动特效，不绑定具体武器平 A。

每名角色的第一批运行素材建议拆成：

```text
sprites/body/idle_01.png
sprites/body/idle_02.png
sprites/body/run_01.png
sprites/body/run_02.png
sprites/body/jump_01.png
sprites/body/dodge_01.png
sprites/body/parry_01.png
sprites/body/hit_01.png
sprites/body/skill_cast_01.png
sprites/body/ultimate_cast_01.png
```

角色专属特效建议拆成：

```text
sprites/vfx/passive_01.png
sprites/vfx/skill_start_01.png
sprites/vfx/skill_loop_01.png
sprites/vfx/skill_hit_01.png
sprites/vfx/ultimate_start_01.png
sprites/vfx/ultimate_domain_01.png
sprites/vfx/ultimate_hit_01.png
```

角色差异方向：

- 凌霜：冰蓝、白、银；冰棱、冷雾、碎冰、蓝白弧形剑痕。
- 墨痕：黑墨、炭灰、深靛；墨雾、笔刷残影、墨滴、墨涡。
- 素心：青绿、暖白、淡粉、浅金；花瓣、气流、玉色柔光、莲形护盾。

## 武器素材

武器素材负责武器外观、平 A 动作语言、蓄力状态、蓄力释放、反击闪光和攻击轨迹。武器不绑定角色。

每种武器的第一批运行素材建议拆成：

```text
sprites/model/weapon_01.png
sprites/model/weapon_sheathed_01.png
sprites/attack/normal_1_arc_01.png
sprites/attack/normal_2_arc_01.png
sprites/attack/normal_3_arc_01.png
sprites/attack/charge_level_1_01.png
sprites/attack/charge_level_2_01.png
sprites/attack/charge_release_01.png
sprites/attack/counter_flash_01.png
```

武器差异方向：

- 长剑：修长、克制、直线感强；蓝白剑光、细长弧线、清俊速度线。
- 大刀：宽刃、厚重、压迫感；黑金墨刷、地裂、尘爆、重斩冲击。
- 双刃：短距、高速、交叉；青白残影、X 形切割、密集碎弧。

## 图像制作标准

运行素材建议遵守以下标准：

- 格式：透明背景 PNG。
- 角色单帧推荐高度：512 到 768 像素。
- 特效单帧推荐尺寸：512x512 或 1024x512。
- 角色面向：默认向右，游戏内需要向左时优先水平翻转。
- 命名：全部使用小写英文、数字和下划线。
- 边缘：保留柔和半透明像素，避免硬抠边。
- 留白：每帧四周至少保留 8 到 16 像素安全边距，避免特效被裁切。

## 接入顺序

建议不要一次性替换全游戏美术。第一阶段只做一个垂直切片：

1. 凌霜 body idle/run/jump/dodge/parry/hit。
2. 长剑 normal_1/normal_2/normal_3/charge_release。
3. 凌霜 skill_start/skill_hit/ultimate_domain。
4. 竹林月夜背景一张分层背景图。
5. 游戏代码先读取这组 PNG，验证缩放、碰撞框、攻击框和特效层级。

垂直切片通过后，再批量处理墨痕、素心、大刀和双刃。

## 运行时读取建议

未来游戏代码可以通过配置文件读取素材，而不是把路径写死在代码里。建议结构：

```json
{
  "characters": {
    "lingshuang": {
      "body": "assets/art/characters/lingshuang/sprites/body/",
      "vfx": "assets/art/characters/lingshuang/sprites/vfx/"
    }
  },
  "weapons": {
    "longsword": {
      "model": "assets/art/weapons/longsword/sprites/model/",
      "attack": "assets/art/weapons/longsword/sprites/attack/"
    }
  }
}
```

这样后续替换素材时，只需要保证命名和目录一致，代码层不必反复改动。
