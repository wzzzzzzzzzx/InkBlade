# 墨刃当前稳定节点验收记录

记录目的：把当前可运行版本固定为一个可回退、可继续开发的稳定节点。后续重做素心或墨痕素材时，应先保证本记录中的基础验收仍然通过。

## 当前节点范围

- 战斗闭环：主菜单、角色选择、武器选择、难度选择、战斗、结算。
- 练习模式：可进入战斗，默认可回满能量并触发大招。
- 角色素材：凌霜、墨痕、素心均已接入运行时 body sprite。
- 视觉训练场：支持 3 名角色的待机、跑步、大招、蓄力释放、受击、小技能、平 A、蓄力、跳跃、振刀、闪避截图。
- 素心死亡判定：素心作为玩家或敌人时，生命归零都必须进入结算。

## 后续素材变更原则

- 先在 staging 或 concept 目录生成候选图，人工确认后再覆盖运行时文件。
- 运行时文件只保留当前被游戏加载的一版，不保留失败变体。
- 若要修透明边缘，优先回到母版重新抠图；像素级补绘只用于小范围临时修复。
- 每次覆盖运行时素材后都重新跑视觉训练场，并保留最新截图用于对比。
